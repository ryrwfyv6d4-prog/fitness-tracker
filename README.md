# NormTube

The Norm Macdonald archive library. The app lives in [`norm-archive/`](norm-archive/README.md) and deploys through Vercel from that folder.

`docs/norm/index.html` is an older single-file version of the library.

The old fitness tracker's code was removed on 2026-10-28. It is still in git history, and its last build stays on the `gh-pages` branch.
